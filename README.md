# MLOps Monitoring — Prototype

Detect drift with PSI and emit alerts/report from reference and current samples.

**Status:** demo/prototype, not production ready. Uses public-free or synthetic sample content, never customer data.

## Run

```powershell
cd 04-mlops-monitoring
python -m pip install -r requirements.txt
python app.py
```

See `app.py` for implementation. A successful local run is needed before publishing.
